# Stage 6: Frontend Document Management UI

## Status: Complete

## Overview
Stage 6 adds document management UI to the case workspace: document upload during evidence
creation, document listing in the evidence section, and download/delete actions per document.

## Changes

### 1. File Upload Helper
**File:** `web/js/api.js:42`

Added `apiUpload(path, file, extraFields, responseType)` and `apiDownload(path)` functions:
- `apiUpload` — uses `FormData` to send multipart/form-data for file uploads (required because
  the existing `api()` helper only supports JSON bodies)
- `apiDownload` — returns the raw `Response` object so the handler can extract headers
  (Content-Disposition for filename, Content-Type, Content-Length, X-Checksum-Sha256)
  and stream the blob for download

### 2. Evidence Modal — File Upload
**File:** `web/index.html:733`

Added file input field to the evidence modal:
```html
<input id="ev-file" type="file" accept=".pdf,.jpg,.jpeg,.png,.gif,.webp,.txt,.csv,.html,.json,.zip,.xlsx">
```

### 3. Evidence Submission — Inline Upload
**File:** `web/js/app.js:1432`

Modified `submitEvidence` to:
1. Create the evidence record via API
2. If a file was selected, upload it to `POST /evidence/{id}/upload`
3. Clear the file input after upload

### 4. Evidence Section — Document List
**File:** `web/js/app.js:1199`

Enhanced the evidence section rendering to include a "Documents" column per evidence item.
After rendering the table, each evidence row triggers `renderEvidenceDocuments(evidenceId, rowIdx)`
which:
- Fetches `GET /evidence/{id}/documents` (paginated list)
- Renders each document with: download link, file size, and delete button
- Shows "No documents" when the list is empty
- Shows a loading spinner while fetching

### 5. Document Management Methods
**File:** `web/js/app.js:1267`

Added three new methods:
- `renderEvidenceDocuments(evidenceId, rowIdx)` — fetches and renders document list
- `downloadDocument(evidenceId, ev)` — calls `apiDownload`, extracts filename from
  Content-Disposition header, creates a blob URL, and triggers a browser download
- `deleteDocument(evidenceId, docId, ev)` — prompts for confirmation, sends DELETE
  request, shows success/error toast, reloads the case sections

### 6. File Size Formatting
**File:** `web/js/app.js:1260`

Added `formatFileSize(bytes)` helper that converts bytes to human-readable format
(B, KB, MB) with 1 decimal precision for KB/MB.

### 7. CSS Styles
**File:** `web/css/style.css`

Added styles for:
- `.loading-spinner.small` — smaller spinner (12px) for inline loading
- `.doc-item` — document item layout (flex row with gap)
- `.error-text` — error text color using `--danger` variable
- `.btn.tiny` — compact button for delete actions (2px padding, smaller font)
- `.btn.btn-danger` — danger-colored button for delete actions

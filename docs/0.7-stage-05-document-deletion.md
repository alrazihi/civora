# Stage 5: Document Deletion & Cleanup

## Status: Complete

## Overview
Stage 5 implements document deletion via API, including storage backend cleanup,
audit logging, and a repository-level delete operation. Builds on Stage 4's
document listing and download auditing.

## Changes

### 1. Repository Interface — `DeleteDocument`
**File:** `internal/evidence/domain/repository.go:31`

Added `DeleteDocument(ctx, orgID, id) error` to the `EvidenceRepository` interface.
Returns `domain.ErrDocumentNotFound` if no document exists for the given ID
within the organization.

### 2. Postgres Implementation
**File:** `internal/evidence/infrastructure/postgres/evidence_repository.go`

`DeleteDocument` executes a DELETE query on `evidence_documents` filtered by
`organization_id` and `id`, then checks `RowsAffected` to confirm the document
existed. Uses a parameterized query to prevent SQL injection.

### 3. Migration 0034
**File:** `migrations/0034_evidence_document_delete_audit.{up,down}.sql`

Extends the `audit.audit_events.valid_audit_action` CHECK constraint to include
the new `evidence.document_deleted` action. The down migration reverts to the
prior vocabulary (without this action).

Note: This is a CHECK constraint extension, not a column addition. The constraint
is dropped and re-added with the full action list including the new value.

### 4. Service Layer
**File:** `internal/evidence/application/service.go:583`

- Added `DeleteDocumentParams` struct (OrganizationID, DocumentID, DeletedBy)
- Added `DeleteDocument` service method with workflow:
  1. Validate `DeletedBy` is non-nil
  2. Verify deleter belongs to organization (UserChecker)
  3. Fetch document metadata by ID (`FindDocumentByID`) — needed for audit + storage key
  4. Delete file from storage backend (`storage.Delete`)
  5. Delete document metadata from database (`repo.DeleteDocument`)
  6. Record `evidence.document_deleted` audit event with file checksum, size, content type

### 5. API Handler
**File:** `internal/evidence/api/handler.go`

- Added `DeleteDocument` to the `EvidenceService` interface
- Added `DELETE /api/v1/organizations/{orgId}/evidence/{evidenceId}/documents/{documentId}` route
- Added `DeleteDocument` handler:
  - Parses org ID, evidence ID (unused but validated for route consistency), document ID
  - Extracts actor ID from auth middleware
  - Calls `svc.DeleteDocument` with auth + ownership checks
  - Returns `204 No Content` on success

### 6. Mock Repository Updates
**File:** `internal/evidence/application/service_test.go`

- Enhanced `mockEvidenceRepo` to store/retrieve documents in-memory (`documents` map)
- `FindDocumentByID` now searches all documents by ID
- `SaveDocumentTx` appends to the documents map
- `ListDocuments` returns paginated documents from the map
- `DeleteDocument` removes from the map, returns `ErrDocumentNotFound` if not found

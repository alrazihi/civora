# Stage 8: Drag-and-Drop Upload & Complete Document UI

## Status: Complete

## Overview
Stage 8 completes the document management frontend with drag-and-drop file upload,
upload progress visualization, file size formatting, and image preview thumbnails.

## Changes

### 1. Drag-and-Drop Upload Zone
**File:** `web/index.html:733`

Replaced the simple file input with a drag-and-drop zone:
- `#ev-drop-area` — A styled dashed-border container that accepts file drops
- Hidden `<input id="ev-file">` inside the drop area (label click still works for browsing)
- `#ev-upload-progress` — A progress bar element below the drop area (initially hidden)

### 2. Drag-and-Drop Handlers
**File:** `web/js/app.js:1272`

Three event handlers:
- `handleDragOver(ev)` — Prevents default, adds `drop-area-hover` class for visual feedback
- `handleDragLeave(ev)` — Prevents default, removes `drop-area-hover` class
- `handleDrop(ev)` — Prevents default, extracts files from `dataTransfer.files`,
  assigns them to the hidden file input

### 3. Upload Progress Bar
**File:** `web/js/app.js:1499`

`submitEvidence` now uses `apiUploadWithProgress` (XHR-based) with:
- Visible progress bar (`#ev-upload-progress`) shown during upload
- Progress fill width updated via the `onProgress` callback
- Progress bar hidden in `finally` block
- Removed old `showUploadProgress`/`updateUploadProgress` methods (used inline approach instead)

### 4. File Size Formatting
**File:** `web/js/app.js:1268`

Added `formatFileSize(bytes)`:
- < 1024 → "N B"
- < 1 MB → "N.N KB"
- >= 1 MB → "N.N MB"

### 5. File Type Icon & Preview
**File:** `web/js/app.js:1279`

- `getFileIcon(contentType)` — Returns appropriate icon based on MIME type:
  image → `icon('image')`, PDF/spreadsheet → `icon('file-text')`, otherwise → `icon('file')`
- `getDocumentPreview(d)` — Returns `<img>` thumbnail for image documents (using the
  download endpoint as src), or calls `getFileIcon` for non-image documents

### 6. CSS Styles
**File:** `web/css/style.css:1035`

Added:
- `.drop-area` — Dashed border, padding, transition
- `.drop-area-hover` — Primary border color, subtle background on drag-over
- `.drop-area-label` — Flex column layout for icon + text
- `.upload-progress-bar` — Visible progress bar container
- `.doc-preview img.doc-thumbnail` — 32x32px image thumbnails

### 7. Bug Fix — Cell Index
**File:** `web/js/app.js:1513`

Fixed `renderEvidenceDocuments` to access `cells[3]` (Documents column) instead of
`cells[2]` (now Status column) after adding Status and Actions columns.

### 8. E2E Tests (2 new)
- `evidence modal has drag-and-drop upload area` — Verifies drop area, file input, and progress bar render in the modal
- `drag-over state is applied when file is dragged over drop area` — Tests `drop-area-hover` class toggles on dragover/dragleave events

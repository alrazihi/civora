# Stage 7: Frontend Document Previews & Upload Progress

## Status: Complete

## Overview
Stage 7 adds frontend polish to the document management UI: image preview thumbnails
for documents, file size formatting, upload progress indicators, and a `download`
helper in the API layer.

## Changes

### 1. File Size Formatting
**File:** `web/js/app.js:1260`

Added `formatFileSize(bytes)` helper that converts bytes to human-readable format:
- < 1024 B → "N B"
- < 1 MB → "N.N KB"
- >= 1 MB → "N.N MB"

Uses `toFixed(1)` for one decimal place.

### 2. File Type Icon & Preview
**File:** `web/js/app.js:1267`

Added two methods:
- `getFileIcon(contentType)` — returns an appropriate icon based on content type:
  - Image types → `icon('image')`
  - PDF/spreadsheet → `icon('file-text')`
  - Other → `icon('file')`
- `getDocumentPreview(d)` — returns an `<img>` thumbnail for image documents
  (using the download endpoint as the image source), or calls `getFileIcon` for
  non-image documents

### 3. Document Rendering Enhancement
**File:** `web/js/app.js:1482`

Modified the evidence section rendering to:
- Add a "Documents" column to the evidence table
- Show a loading spinner in each row's Documents cell
- Call `renderEvidenceDocuments()` after rendering to fetch and display documents
  per evidence item
- Show thumbnail + file name + size + download link + delete button per document

### 4. Document List Rendering
**File:** `web/js/app.js:1510`

`renderEvidenceDocuments(evidenceId, rowIdx)`:
- Fetches `GET /evidence/{id}/documents`
- Renders each document with thumbnail, download link, formatted file size, and delete button
- Shows "No documents" for empty lists
- Shows error text on fetch failure (except 404)

### 5. Upload Progress Indicator
**File:** `web/js/app.js:1491`

`submitEvidence` now uses `apiUploadWithProgress` (XHR-based) instead of `apiUpload` (fetch-based)
to track upload progress. Shows a progress bar next to the submit button:
- `showUploadProgress(buttonEl, percent)` — creates and inserts a progress bar element
- `updateUploadProgress(container, percent)` — updates the bar width
- Progress bar is removed on completion or error

### 6. API Helpers
**File:** `web/js/api.js:74`

Added two new API helper functions:
- `apiUploadWithProgress(path, file, extraFields, onProgress)` — uses XMLHttpRequest
  to send multipart form data with upload progress events. Returns a Promise that
  resolves with the parsed JSON response. The `onProgress` callback receives
  a percentage (0-100).
- `apiDownload(path)` — sends a GET request and returns the raw `Response` object
  (not parsed JSON), allowing the caller to access response headers and stream
  the body as a blob for file downloads.

### 7. CSS Styles
**File:** `web/css/style.css:1029`

Added styles for:
- `.loading-spinner.small` — 12px spinner with 1px border
- `.doc-item` — flex layout for document items
- `.error-text` — danger-colored error text
- `.btn.tiny` — compact button (2px padding, small font)
- `.btn.btn-danger` — red danger button for delete actions with hover state
- `.doc-preview img.doc-thumbnail` — 32x32px image preview with object-fit cover

### 8. File Input in Modal
**File:** `web/index.html:733`

Added file input field to the evidence modal:
```html
<input id="ev-file" type="file" accept=".pdf,.jpg,.jpeg,.png,.gif,.webp,.txt,.csv,.html,.json,.zip,.xlsx">
```

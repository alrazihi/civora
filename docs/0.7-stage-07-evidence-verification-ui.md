# Stage 7: Evidence Verification Workflow UI

## Status: Complete

## Overview
Stage 7 adds evidence verification controls to the case workspace UI: verification
status badges, verify/reject buttons for unverified evidence, and API integration
for performing verification actions.

## Changes

### 1. Evidence Section Rendering — Verification Status & Actions
**File:** `web/js/app.js:1199`

Enhanced the evidence section rendering to include:
- **Status column** — Shows a badge with the verification status (PENDING, VERIFIED, etc.)
- **Actions column** — Shows Verify/Reject buttons for unverified evidence, or "Action taken" for already-verified/rejected evidence
- Uses `cssStateClass` for badge CSS class naming consistent with the rest of the app

### 2. Evidence Action Rendering
**File:** `web/js/app.js:1595`

Added `renderEvidenceActions(e)` method that:
- Returns "Action taken" for verified or rejected evidence
- Returns Verify button (green) and Reject button (red) for unverified/needs-review evidence

### 3. Evidence Verification API
**File:** `web/js/app.js:1611`

Added `verifyEvidence(evidenceId, status, ev)` method that:
- Prompts the user for a reason via `prompt()`
- Sends POST to `/evidence/{id}/verify` or `/evidence/{id}/reject`
- Reloads the case sections to show updated status

### 4. Document Preview Rendering Fix
**File:** `web/js/app.js:1478`

Fixed `renderEvidenceDocuments` to access `cells[3]` (Documents column) instead of
`cells[2]` (now Status column) after adding the Status and Actions columns.
